Deux milieux : choisissez chaque milieu dans la liste ou saisissez un indice dans la case de droite. Orientez le laser avec le curseur ou en le faisant glisser dans le milieu du haut.
Demi-disque : faites glisser le laser, le demi-disque ou la couronne du rapporteur pour les faire tourner. Aligner le rapporteur place son 0° sur la normale.

Source : faites-la glisser pour la déplacer, tirez sa poignée ronde pour l'orienter.
Prisme : faites-le glisser pour le faire tourner ; matériau, angle au sommet et incidence se règlent dans le panneau.
Zoom : molette ; en vue zoomée, le glisser déplace la vue, le double-clic la réinitialise.
Écran : l'encart de droite montre la tache agrandie dix fois.
