Le loquet bloque le piston : posez la masse, puis libérez le loquet pour une compression brutale. Le curseur Vitesse descend jusqu'à ×1/5000 pour suivre les ondes dans le gaz. Les lignes du gaz séparent des tranches de même masse. Le cylindre est élargi sur le dessin (section réelle : 20 cm²).
Raccourcis : Espace = pause, R = réinitialiser.
☰ Menu Informations
Chaque choc d'une molécule sur une paroi exerce une force. La pression macroscopique P résulte de la somme statistique de ces chocs. Le piston se saisit directement à la souris pour faire varier V.
Raccourcis : Espace = pause, R = réinitialiser.
